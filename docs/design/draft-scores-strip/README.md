# Draft scores strip

UX reference for the unverified-scores strip on Home. Product lock below supersedes the mock label where they differ. The Home curtain is out of scope — mocks that say “Draft scores live” / “Scores pending” on the curtain are not the spec.

## Locked product

- Site Admin drafts a night’s scores before official publish (**Draft Scores** on Enter Results).
- **Mark Watched — I've Finished It (ET)** unlocks those drafts and the standings that come from them.
- **Stay Updated — I'm Watching Live** does not unlock drafts.
- While drafts are visible, one sticky strip (Pattern B: wordmark + avatar + strip stay together on scroll):

**Strip label:** `Draft scores · Site Admin to verify` + amber/gold **(i)** only. No Mark Watched button on this strip.

**(i) sheet**

- Title: `Draft scores`
- Body: `Site Admin has drafted tonight's scores before official publish. Standings may update from these drafts and can change when scores are verified and published.`
- Primary: `Got it`

**Chrome:** amber soft-inset rhyme of the Spoiler-Free soft inset (warm warning tint, one hairline under the sticky stack). Distinct from the mauve Spoiler-Free strip. One sticky strip max — the draft strip replaces the Spoiler-Free strip.
