# Post–East draft opt-in gap — UX proposals

**Mock Mosaic · planning only · eng stays with Claude via Push Pilot**  
**Constraint:** Do not reopen mid-East Mark Watched gray lock (gray until episode completed; no soft subtext under gray).

## Gap (agreed)

Drafts unlock today only via:
1. Mid-East **Stay Updated** during the East air window, or
2. **Mark Watched / I’ve Finished It**

If someone is watching **East delayed / after East air ends** (e.g. 10:30 ET) and has **not** marked finished — especially **SF off** (no Soft inset strip) — there is no path to opt into **draft** scores. The live-air prompt is gone outside air windows. Mark Watched means “I’ve finished,” which is the wrong claim for someone still catching up.

---

## Option A — Recommended: Post–East **Follow along** Home strip (SF-agnostic)

**When it shows**
- East air window has **ended**
- Scores are still in **draft** state (Site Admin hasn’t moved to West/published feed yet)
- User has **not** Stay Updated and **not** Mark Watched
- Ends when: user taps Follow along, Mark Watched, West air starts (handoff to West prompt / published path), or drafts are no longer the live state

**Where:** Soft inset under sticky branding (same Pattern B slot as today’s SF posting strip).

**Copy / CTA**
- Line: **Draft scores available** · Follow along  
- Button: **Follow along**  
- Unlock = same as mid-East Stay Updated → drafts + amber **Draft scores · may change** strip replaces this one (don’t stack)

**SF on**
- This strip **replaces** `Spoiler-Free · Week N posting live` for the gap window (don’t stack).
- Mark Watched remains available on the strip *if* episode is completed (post–East); mid-East gray lock unchanged during East air.
- Prefer one primary CTA **Follow along** on this strip; Mark Watched can stay secondary on curtain / Settings / existing Mark Watched entry points so we don’t force “finished.”

**SF off**
- This is the fix: SF-off currently has **no** Soft inset — strip appears only for this gap.

**Why best**
- Reuses a surface users already understand (Soft inset).
- Doesn’t reopen mid-East gray Mark Watched.
- Separates “follow drafts while catching up” from “I’ve finished.”
- Works with SF on and off without inventing a Settings scavenger hunt.

## Option B — Alternate: Gap-window prompt (not “Live Now”)

**When:** Same gap window as A.

**Where:** Bottom sheet on Home open (like live-air), but **not** titled as Live Now East/West.

**Chip:** e.g. **Drafts available** or **East ended · drafts posting** (no clock; not Live Now · East Coast).

**Buttons**
- Primary: **Stay Updated — I'm Watching Live** (or shorten to Stay Updated / Follow along) → drafts
- Secondary: **Mark Watched — I've Finished It** — **enabled** (episode completed; mid-East gray does not apply here)
- Ghost: Dismiss → stay gated; strip from Option A can still cover SF-off if they dismiss

**SF on/off:** Prompt for anyone in the gap; SF toggle still wires to Settings. Soft inset optional backup if dismissed.

**Tradeoff:** Extends “required choice sheet” past air windows (product previously narrowed those). Heavier than a strip. Good if you want the same three-choice vocabulary outside air.

---

## Option C — Light fallback: one-shot banner + Settings

**When:** Same gap; one-shot per week (dismissible).

**Where:** Home one-shot banner under branding **and/or** Settings › Spoiler-Free block: **Show draft scores** while drafts exist.

**SF on:** Banner optional if Soft inset already offers Mark Watched; still useful for Follow-drafts without finishing.  
**SF off:** Banner is the main Home cue; Settings is backup.

**Tradeoff:** Easy to miss; Settings is secondary. Use only if A/B feel too prominent.

---

## Recommendation

Ship **Option A**. Keep mid-East gray Mark Watched exactly as locked. Do **not** treat Mark Watched as the delayed-watcher draft path. Option B only if you want the sheet vocabulary in the gap. Option C as polish, not the sole fix.

- Mid-East Mark Watched gray / no soft subtext (locked)
- West / SF-off live-air remocks (wait until Kylie asks)
